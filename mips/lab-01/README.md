# Laboratório 01 - Eco

Primeira prática desenvolvida em Assembly MIPS na disciplina de Arquitetura de Sistemas Computacionais.

## Objetivo

Desenvolver um programa capaz de ler um número inteiro informado pelo usuário e imprimir o mesmo valor na saída.

## Conceitos utilizados

- Entrada e saída por meio de syscalls
- Uso de registradores
- Movimentação de dados entre registradores

## Arquivo

- `eco.asm` - implementação do programa em Assembly MIPS
