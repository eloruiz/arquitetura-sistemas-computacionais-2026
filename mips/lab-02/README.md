# Laboratório 02 - Adivinhar Número

Programa desenvolvido em Assembly MIPS que solicita ao usuário um número inteiro entre 0 e 100.

Após armazenar o número informado, o programa solicita novos valores até que o usuário digite novamente o número inicial.

## Conceitos utilizados

- Entrada e saída com syscalls
- Registradores
- Comparações
- Desvios condicionais
- Estrutura de repetição
- Armazenamento de dados em byte

  ## Arquivo

- `adivinhar_numero.asm` - implementação do programa em Assembly MIPS
